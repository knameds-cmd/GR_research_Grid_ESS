## 0. 한 장 요약

- **연구 주제**: 영국(GB) 시장의 어떤 규칙이 계통용 배터리를 수익 사업으로 만들었고, 각 규칙이 수익과 운전 전략을 얼마나 바꾸는가. 교수님 국가 비교 구도(호주·영국·북유럽·한국) 중 영국 담당.
- **지금 상태**: 문헌(114편)과 경쟁 논문 분석 완료. 데이터는 대부분 받았지만 **BM 데이터가 거의 없음**. 모델은 **버릴 프로토타입**.
- **방법 판단**: 규칙 스위치 + 국면 분할은 조건부로 유효하다. 오류 없는 비교는 불가능하므로 **실제 수익 재구성(A) → 시뮬레이션 검증(B) → 준실험·공급곡선 교차 확인(C·D)**의 구조로, 결과를 범위로 낸다.
- **가장 먼저 할 일**: ① 결정 4개(1장) ② 배터리 BMU 매핑과 BM 데이터 확보 ③ 실제 수익 재구성. 엔진 재구축은 그 다음이다.
- **마감**: 파견 종료 2026-12-10. 교수님 중간 보고 11/3~11/9 주간.
