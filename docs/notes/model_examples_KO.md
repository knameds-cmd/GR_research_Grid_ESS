# 구조층 2단계 모형의 손계산 예제 (E1~E4)

> 작성 2026-11-05. 코드: `gbess/system/` (`stage1.py`, `redispatch.py`, `planner.py`, `network.py`). 시험: `tests/test_system_model.py`. 여기 숫자는 시험에 그대로 들어 있습니다. 문서와 코드가 어긋나면 시험이 실패합니다.
> 모형 정의는 [`../IMPLEMENTATION_A_KO.md`](../IMPLEMENTATION_A_KO.md) 2장, 사전등록은 `gbess/config/spec.yaml`.

**공통 가정**
- 구역 N(북), S(남) 두 개. 경계 한도 100 MW. 각 구간은 1시간. 저장 효율 100%. 끝 저장량 제약 없음.
- **동률 깨기**: 효율이 100%면 가스로 충전해 가스를 대신하는 것이 손익 0이라 풀이기가 아무 해나 고를 수 있습니다. 그래서 저장에 방전 1 MWh당 £0.01의 아주 작은 가변비용을 둡니다. 아래 금액에는 그 몫(방전량 × £0.01, 최대 £1)이 빠져 있고, 시험은 £2 오차로 비교합니다.
- 계통 비용 = 연료비(가스 MWh × 단가) + 저장 가변비용 + 정전 비용. 왜곡 D = C(S0, 재급전 변형) − C(S6).

## E1. 북쪽 저장이 "덜 충전"하는 왜곡 (03 문서 6.3)

| | t1 | t2 |
| --- | --- | --- |
| N 풍력 (£0) | 300 | 0 |
| N 수요 | 50 | 50 |
| S 수요 | 200 | 200 |
| S 가스 | £100/MWh, 충분 | |
| N 저장 | 100 MW·100 MWh, 빈 채로 시작 | |

| 판 | 운전 | 비용 |
| --- | --- | --- |
| 1단계 (전국 시장) | t1 풍력 300 = 수요 250 + 충전 50. t2 방전 50 + 가스 200. 암묵적 조류 t1 = 300 − 50 − 50 = **200** (한도 100 초과) | £20,000 |
| S6 계획자 최적 | t1 조류 100, 충전 100, 출력제한 50, 가스 100. t2 방전 100 → N 수요 50 + 남쪽 50, 가스 150 | **£25,000** |
| 재급전 (i) 발전기만 | t1 N 풍력 −100, S 가스 +100. 재급전 £10,000 | **£30,000** (D = £5,000) |
| 재급전 (ii) 저장도 | t1 충전 +50, t2 방전 +50. 재급전 £5,000 | **£25,000** (D = 0) |
| 재급전 (iii) W1 북쪽 고정 | 이 저장이 W1 북쪽이면 (i)과 같음 | £30,000 (D_W1 = £5,000) |

## E2. 북쪽 저장이 1단계에서 "방전"해 경계 조류를 늘리는 왜곡

전국 가격이 높은 시간에 북쪽 저장이 차 있어서, 북쪽 바람이 많은데도 방전하는 경우입니다. 설계안 S1b(제약 시간 방전 금지)가 효과를 내는지 보려고 만들었습니다.

| | t1 | t2 |
| --- | --- | --- |
| N 풍력 (£0) | 200 | 0 |
| N 수요 | 50 | 50 |
| S 수요 | 500 | 150 |
| S 싼 가스 | £50/MWh, 200 MW | |
| S 비싼 가스 | £150/MWh, 충분 | |
| N 저장 | 100 MW·100 MWh, **가득 찬 채로** 시작 | |

**1단계 (전국 시장)**
- t1: 순수요 = 550 − 200 = 350. 전국 가격 £150(비싼 가스). 저장이 100을 모두 방전하면 비싼 가스 100을 줄여 £15,000을 아낍니다. t2에 방전하면 싼 가스만 줄여 £5,000입니다. 그래서 **t1에 전부 방전**하고, 해는 하나로 정해집니다.
- t1 가스: 싼 200 + 비싼 50 = £17,500. t2: 싼 200 = £10,000. 합계 **£27,500**.
- 암묵적 조류 t1 = 200 + 100 − 50 = **250** (한도 100 초과).

**S6 계획자 최적**
- t1: 북쪽 수출이 100으로 묶이므로 t1 방전은 쓸모가 없습니다(풍력만 줄이게 됨). 풍력 150, 수출 100. 남쪽 400 = 싼 200 + 비싼 200 → £40,000.
- t2: 방전 100 → N 수요 50 + 남쪽 50. 남쪽 100 = 싼 가스 100 → £5,000.
- 합계 **£45,000**.

**재급전**

| 변형 | 운전 | 최종 비용 | 재급전 비용 | D |
| --- | --- | --- | --- | --- |
| (i) 발전기만 | t1 방전 100 그대로 → 풍력 ≤ 50. 남쪽 400 = £40,000. t2 북쪽 수요 50을 남쪽에서 받음 → 싼 가스 200 = £10,000 | **£50,000** | £22,500 | **£5,000** |
| (ii) 저장도 | 계획자 최적과 같음 | £45,000 | £17,500 | 0 |

**설계안 손계산 (T6에서 시험으로 씀, 미리 적어 둠)**
- **S1b** (β = 1.0): S0 1단계에서 t1 조류 250 ≥ 100이라 t1을 표시합니다. 다시 푼 1단계에서 t1 방전을 막으면 t2에 방전합니다. 1단계 £32,500 + £5,000 = £37,500, 조류 t1 150, t2 50. 재급전 (i): t1 풍력 150으로 줄이고 남쪽 400 = £40,000, t2 £5,000 → **£45,000 = S6** (D = 0). 이 예에서는 S1b가 왜곡을 모두 없앱니다.
- **S1a** (X = 50%): 1단계에서 t1 50, t2 50 방전 → £25,000 + £7,500 = £32,500. t1 조류 200. 재급전 (i): t1 풍력 ≤ 100, 남쪽 400 = £40,000. t2 북쪽 순공급 0, 남쪽 150 = £7,500 → **£47,500** (D = £2,500). 왜곡이 절반으로 줍니다.
- 비교: E1(덜 충전형 왜곡)에서는 S1a·S1b가 방전·충전 한도를 거는 설계라 왜곡을 줄이지 못할 수 있습니다(지시서 2.6 연구 메모). T6에서 확인합니다.

## E3. 1단계 해가 여럿인 경우 (D_lo < D_hi)

한 시간. 같은 저장이 북쪽과 남쪽에 하나씩 있습니다.

| | |
| --- | --- |
| N 풍력 (£0) | 200 |
| N 수요 / S 수요 | 50 / 200 |
| S 가스 | £100/MWh |
| 저장 N, S | 각각 50 MW·50 MWh, 가득 찬 채로 시작 |

- 1단계: 순수요 250 − 200 = 50을 저장 하나가 채우면 됩니다. 북쪽이 하든 남쪽이 하든 비용이 같습니다(가스 0). **해가 하나로 정해지지 않습니다.**
- 북쪽 저장이 방전하는 계획: 조류 200 + 50 − 50 = 200. 재급전 (i)에서 풍력을 100까지 줄이고 남쪽은 100 + 가스 100 → £10,000.
- 남쪽 저장이 방전하는 계획: 조류 150. 재급전 (i)에서 풍력 150, 수출 100, 남쪽 100 + 저장 50 + 가스 50 → £5,000.
- S6: £5,000. 그래서 **D_lo = 0, D_hi = £5,000.**
- 코드 확인: `redispatch_lo`(결합 LP)는 남쪽 방전 계획을 고릅니다. `redispatch_hi`(극단 계획: W1 북쪽 방전 최대)는 북쪽 방전 계획을 고릅니다.

## E4. 묶은 저장 때문에 재급전을 풀 수 없는 경우

한 시간. 북쪽에는 수요와 발전기가 없고 저장 150 MW(가득 참)만 있습니다. 남쪽 수요 300, 가스 £100.

- 1단계: 저장 150 방전, 가스 150 → £15,000. 암묵적 조류 150 > 한도 100.
- 재급전 (i)에서 저장을 1단계 계획(방전 150)에 묶으면, 북쪽에서 줄일 발전기가 없어 조류를 100으로 낮출 방법이 없습니다. **실행 불가능합니다.**
- 실제 2030년에도 일어날 수 있습니다. W1 북쪽 장주기는 5,100 MW인데, 2025년 B4 한도 중앙값은 약 2,150 MW입니다. 이들이 함께 방전하는 계획이면 풍력을 0까지 줄여도 넘칠 수 있습니다.
- spec.yaml은 이 경우를 정하지 않았습니다. 코드에는 두 처리를 넣어 두었습니다.
  - `infeasible="strict"`(기본값, spec 문구 그대로): 실패로 멈춤
  - `infeasible="min_deviation"`: 묶은 저장의 계획 이탈량을 먼저 최소화(여기서는 방전 150 → 100, 이탈 50 MWh)하고, 그 안에서 비용을 최소화합니다. 재급전 비용 £5,000(가스 200). 이탈량은 결과에 따로 남깁니다.
- **연구자 결정 필요** (T5 보고에서 여쭘).
