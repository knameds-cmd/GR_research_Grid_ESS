# M1 go/no-go 계산 (T9)

> 작성 2026-11-05. **판정은 연구자가 내린다.** 이 문서는 spec.yaml `go_no_go` 규칙에 값을 넣어 계산한 결과만 적는다. 계산 코드: `gbess.system.run_m1.go_no_go_values`, `check_invariants` (시험 `tests/test_system_run_m1.py`). 결과표와 읽는 법: [`m1_results_KO.md`](m1_results_KO.md).

## 1. 검산 (먼저)

spec의 검산 다섯 항목이 세 한도 배율 모두에서 성립한다. 위반이 없으므로 판정 계산으로 넘어간다.
- C(S6) ≤ C(S0, ii) ≤ C(S0, iii) ≤ C(S0, i)
- |C(S0, ii) − C(S6)| ≤ 10⁻⁶ C(S6)
- |C(S5) − C(S6)| ≤ 10⁻⁶ C(S6)
- C(S1a), C(S1b) ≥ C(S6)
- D_lo ≤ D_hi

## 2. 규칙에 들어가는 값 (£m/년)

M = £25m/년, go 문턱 3M = £75m/년 (연구자 결정 2026-11-05). D는 D_W1 = C(S0, iii) − C(S6)이다.

| 한도 배율 | D_lo | D_hi (근사) | E_bind (TWh) | C(S0) − C(S1a) | C(S0) − C(S1b) |
| --- | --- | --- | --- | --- | --- |
| ×0.8 | 210.1 | 235.5 | 6.03 | +179.2 | +70.6 |
| ×1.0 | **48.2** | 113.7 | 5.72 | +5.3 | −43.9 |
| ×1.2 | 23.6 | 70.8 | 5.32 | −21.9 | −56.2 |

C(S0) − C(S1x)는 재급전 (iii) D_lo 판끼리 비교했다(주 지표 D_W1과 같은 변형).

## 3. 규칙대로 계산한 결과: **조건부 (conditional)**

| 규칙 | 조건 | 값 | 성립? |
| --- | --- | --- | --- |
| no-go | ×1.0과 ×0.8 모두 D_lo < M | 48.2 ≥ 25, 210.1 ≥ 25 | 아니오 |
| go | ×1.0 D_lo ≥ 3M | 48.2 < 75 | **아니오** |
| | ×1.2 D_lo ≥ M | 23.6 < 25 | 아니오 (근소) |
| | E_bind > 0 | 5.72 TWh | 예 |
| | S1a·S1b 중 하나 이상 C(S0) − C(S1x) > 0 (×1.0) | S1a +5.3 | 예 |
| 조건부 | 그 밖 | — | **예** |

spec이 정한 조건부의 다음 단계: **순차 재급전 하나와 바람 많은 기상연도 하나를 더해 다시 판정한다. 순차 재급전의 D가 M보다 작으면 no-go.**

## 4. 판정 전에 보실 점

- ×1.2의 D_lo(£23.6m)는 M(£25m)에 매우 가깝다. 한도 가정이 조금만 달라져도 규칙 결과가 바뀔 수 있다.
- ×0.8의 D_lo는 "묶은 저장 이탈" 129 GWh를 포함한다(spec에 없던 경우의 처리, `redispatch.infeasible_fixed = min_deviation`). 이 판에서는 "W1 북쪽은 재급전할 수 없다"는 가정이 일부 시간에 물리적으로 성립하지 않는다.
- 인터커넥터 제외와 비용 기준 재급전은 D를 작게 만드는 쪽으로 볼 근거가 있다(m1_results 5장). 반대로 경계 한도 감산은 D를 크게 만드는 쪽이다.
- **민감도(판정에 쓰지 않음, 한도 ×1.0)**: 2033년 운전 사업(Coire Glas·Earba·Long Stratton)을 빼면 D_lo £13.2m(D_hi £29.8m), 감산 없는 명목 한도면 D_lo £8.0m(D_hi £30.1m)로 둘 다 M보다 작다. 주 결과가 M 이상인 것은 이 두 가정에 기댄다.
- 결과를 보고 spec(지표, 설계안, 통과 기준, 규칙)을 바꾸자고 제안하지 않는다.

## 5. 다음 단계 선택지 (연구자 결정)

| 선택지 | 내용 | 결과 |
| --- | --- | --- |
| A. spec대로 조건부 절차 | 구간별 순차 재급전(M3에서 하기로 한 `mode="sequential"`)을 먼저 구현하고, 바람 많은 기상연도 1개(ERA5 2010~2024 중 고름)를 더해 다시 판정 | 사전등록 규칙 그대로. 순차 재급전이 실제 값이 [0, D_W1] 어디인지 정함 |
| B. 판정을 다른 세션에 다시 맡김 | 작업하지 않은 세션에 코드와 결과만 주고 다시 계산·판정하게 함 (03 문서 5.3) | 작업 세션이 자기 결과를 채점하는 문제를 피함 |
| C. 방향 재검토 | B안(포트폴리오 견고성)이나 C안(지속시간 요건)의 비중을 늘림 | spec 규칙상 지금은 no-go가 아니므로 이르다 |
