## 2. 검산과 "비교 불가"

- ×1.0·×1.2: 15개 해 모두 검산 위반이 없다(다시 계산 뒤에도 같음).
- ×0.8: 4개 해가 검산을 통과하지 못해 사전등록 규칙("검산이 깨진 판은 '비교 불가'로 따로 셈")에 따라 ×0.8 분포에서 뺐다.

| 해 | 깨진 항목 |
| --- | --- |
| 2016 | C(S0, iii 첫 풀이) ≤ C(S0, i)가 £60.8m 차이로 성립 안 함 |
| 2017 | D_lo ≤ D_hi가 £4.2m 차이로 성립 안 함 |
| 2021 | D_lo ≤ D_hi가 £90.8m 차이로 성립 안 함 |

- 원인은 M1과 같다(`m1_results_KO.md` 5장 1번, 6.1). ×0.8에서는 **15개 해 모두** W1 북쪽을 1단계 계획에 묶으면 풀 수 없는 시간이 있어, `min_deviation`(이탈량을 먼저 줄이고 그다음 비용)으로 풀었다. 이탈량이 판마다 달라 비용 순서가 보장되지 않는다.
  - ×0.8 (iii) 이탈량: 첫 풀이 229~337 GWh, D_lo 60~181 GWh, D_hi 337~560 GWh.
  - ×1.0·×1.2의 (iii) D_lo 판은 15개 해 모두 이탈이 0이다. 주 결과(×1.0 D_lo)는 이 문제가 없다. (처음 메모에는 "(iii)은 모두 이탈 0"이라고 적었으나, 판정에 쓰지 않는 ×1.0 첫 풀이·D_hi 판에는 작은 이탈이 있다: 2011 첫 풀이·D_hi 0.06 GWh, 2015·2022 D_hi 0.10~0.11 GWh.)

- **"따로 센다"의 두 읽기.** spec rules는 "검산이 깨진 판은 '비교 불가'로 따로 셈"이고, 승인한 초안 3.3은 "비교 불가로 표시하고 분포 계산에서 빼지 않고 따로 센다"이다. 처음 요약 코드는 깨진 판을 분포에 넣었고, 결과를 본 뒤 한 번 빼도록 고쳤다가, 초안 문구와 어긋나는 것을 알고 **둘 다 내도록** 바꿨다(`summary.json`의 기본 키 = 뺀 값, `*_all` = 넣은 값). **연구자 결정(2026-11-06): 뺀 값을 주 값으로, 넣은 값을 함께 보고.** 지표·해·판은 바꾸지 않았다. 손계산 시험 `tests/test_system_m3a.py`.

## 2a. 입력 자료 오류: NESO 수요 자료의 잉글랜드·웨일스 칸 (결과를 본 뒤 발견)

- 2011년 정전 시간을 확인하다가 찾았다(7장 1번). NESO Historic Demand Data의 반시간 몇 칸에서 `ENGLAND_WALES_DEMAND`가 0이거나 ND(전국 수요)보다 크다. 입력 코드는 스코틀랜드 수요를 ND − EW로 만들기 때문에, EW가 0인 칸에서는 그 반시간의 스코틀랜드 수요가 전국 수요만큼 커진다. EW > ND인 칸은 0으로 잘린다.
- 2011-04-28 8시(반시간 20번, EW = 0)에 2030 모형의 북쪽 수요가 4,648 MW(앞뒤 시간 약 800 MW), 남부 스코틀랜드 11,068 MW(약 2,000), 잉글랜드·웨일스 14,822 MW(약 29,000)가 됐다. 이 한 시간에 북쪽 정전 1,826 MW가 생겨 2011 D_lo 52.3 중 £31.0m를 차지한다.
- 이상 칸(EW ≤ 0, 또는 (ND − EW) ÷ ND가 0 미만이나 0.25 초과)이 있는 해: 2010 1칸, 2011 1, 2012 1, 2014 2, 2015 2, 2016 2, 2017 3, 2018 4. **2013·2019~2025는 없다**(M1 주 결과·2020 판·M2의 2025 재현은 영향 없음).
- **연구자 결정(2026-11-06): 고치고 다시 계산.** 정제 규칙(`gbess.system.inputs.clean_ew`, spec changelog 2026-11-06): EW ≤ 0 또는 스코틀랜드 몫 (ND − EW) ÷ ND가 0 미만·0.25 초과인 반시간은 오류 칸으로 보고, 그 칸의 몫을 앞뒤 정상 칸의 몫에서 선형으로 이은 뒤 EW = ND × (1 − 몫). 손계산 시험 `test_clean_ew_by_hand`.
- 고친 뒤 2011-04-28 8시의 2030 북쪽 수요는 664 MW, 남부 스코틀랜드 1,582 MW, 잉글랜드·웨일스 30,213 MW로 앞뒤 시간과 맞는다. 2011년 정전은 사라졌다.
- **바뀐 값**(£0.6m 넘게 바뀐 것만):
  - 2011: D_lo ×1.0 52.3 → 20.7, ×0.8 96.7 → 37.3, ×1.2 28.9 → 16.8, D_hi 123.6 → 83.8, D_seq 281.3 → 252.9, W1 북쪽 몫 19.2 → 72.7. 계통 비용은 세 설계안 모두 약 £31m 내려갔다(정전 몫).
  - 2010: D_lo ×0.8 137.9 → 123.7, D_hi 151.9 → 120.8.
  - W1 북쪽 몫(보고만): 2014 46.2 → 84.5, 2015 76.7 → 86.1, 2017 66.1 → 63.5. 입력만 바뀌었으므로 오류 칸 때문이다(어느 시간이 얼마를 냈는지는 확인하지 않음).
  - D_hi(근사): 2015 87.6 → 75.0, 2018 289.2 → 269.1, 2016 198.7 → 199.4.
  - 그 밖에 S1a·S1b 소비자 지급이 2015·2016·2018에 £1.6~11.3m 바뀌었다. 판정 관련 값(D_lo ×1.0, C(S0) − C(S1x))은 2011 말고는 £0.6m 안이다.
- 순위(5장)와 검산(2장)은 고치기 전과 같다.

## 5. 설계안 순위 (2013년과 같은가)

순위는 낮을수록 좋음, 괄호는 (S0, S1a, S1b), £0.1m 미만 차이는 같은 순위(사전등록 세부).

**계통 총비용**: 2013 순위 (1, 0, 2) = S1a < S0 < S1b. **같은 해 5개 / 15개**(2013, 2016, 2021, 2022, 2024).
- 뒤집힌 10개 해 중 9개(2010, 2011, 2012, 2014, 2015, 2017, 2019, 2020, 2023)는 (0, 1, 2) = S0 < S1a < S1b. S0과 S1a 자리만 바뀌었다.
- 2018은 (2, 0, 1) = S1a < S1b < S0.
- **S1b가 가장 비싼 해는 14개**(2018만 예외).
- S0과 S1a의 차이는 2018(+107.2)·2024(+27.0)을 빼면 모두 ±10 안이다(−9.6 ~ +6.8).

**소비자 지급**: 2013 순위 (0, 1, 2) = S0 < S1a < S1b. **같은 해 11개 / 15개**.
- 뒤집힌 해: 2010·2018은 S1a와 S1b 자리가 바뀜(0, 2, 1). 2016·2021은 S1a가 가장 작음(1, 0, 2).
- S0의 소비자 지급이 가장 작은 해는 13개다.

   | 2018 | 2월 4일 2~4·6~10·12~14시 (11시간) | 모두 6,631 (시간마다 51~1,006) | 약 5,040 MW 충전 | 북쪽으로 3,940 MW(한도) | 평균 370 MW |

   - **2013·2018·2024 (같은 구조)**: 전국 시장 계획에서 W1 북쪽 장주기가 전국 가격이 낮은 시간에 거의 최대 출력(약 5.1 GW)으로 충전한다. 그런데 그 시간 북쪽에는 바람이 거의 없어, 충전 전기가 B4를 넘어 북쪽으로 와야 하고 B4 한도(3,940 MW)에 걸린다. 재급전 (iii)은 "W1 북쪽은 1단계 계획을 바꿀 수 없다"고 두므로, 모형은 충전을 줄이는 대신 북쪽 소비자의 공급을 끊는다(정전 1 MWh £17,000). 실제 NESO라면 충전을 멈추라고 지시했을 것이다.
     - 즉 이 몫은 (iii)의 "W1 북쪽은 재급전 불가" 구성에서 나온다. `min_deviation`은 "묶은 저장 때문에 풀 수 없을 때"만 이탈을 허용하는데, 정전 변수가 있어 LP는 늘 풀리므로 이탈 대신 정전을 고른다.
     - 방향도 헤드라인 이야기(북쪽 바람이 남쪽으로 넘침)와 반대다: **북쪽 장주기의 충전이 전기를 북쪽으로 끌어당기는 제약**이다.
   - S1a의 이점이 큰 해(2013 +6.8, 2018 +107.0, 2024 +27.0)는 이 "충전 정전"이 있는 해와 겹친다. S1a는 W1 북쪽의 충전·방전 출력을 줄이므로 이 정전을 피한다.
   - 정전 비용을 빼고 본 값(D_lo − VoLL × 정전량)은 회계상 나눈 것일 뿐 반사실 값이 아니다. 참고로 2013 29.4, 2018 31.4, 2024 40.2이다. 반사실 값은 7a장 '충전 정전' 판이다.
   - **M1 주 결과(2013 D_lo 47.4)에도 이 몫 £18.0m가 들어 있었다.** M1 메모에는 적지 않았던 점이다.
2. **2011년 W1 북쪽 몫.** 고치기 전 19.2로 다른 해보다 훨씬 작았다. 정제 뒤 72.7로 다른 해(45~111)와 비슷해졌으므로 수요 자료 오류 때문이었다.
3. **S1b는 거의 늘 S0보다 비싸다**(14개 해, £21~59m). M1(2013)의 결론이 기상연도를 바꿔도 유지된다.
4. **S1a와 S0은 거의 비긴다.** 중앙값 −1.0으로 S0이 아주 조금 싸고, 부호가 해마다 바뀐다. 그래서 계통 총비용 순위는 2013과 같은 해가 5개뿐이다. 순위 "뒤집힘"의 대부분은 £10m 안의 차이에서 생긴다.
5. **한도 ×1.2에서는 3M을 넘는 해가 없다**(최대 37.3). ×0.8은 해에 따라 21.7~331.7로 크게 흔들리고, 묶은 저장 이탈 때문에 4개 해는 비교 불가다.

## 7a. '충전 정전' 판 (결과 뒤 추가 판, 보고만. 연구자 결정 2026-11-06, spec changelog)

- 충전 정전 판 D는 '정전 비용만 뺀 값'(7장, 2013 29.4, 2018 31.4, 2024 40.2)과 가깝다. 충전을 줄인 만큼의 다른 비용이 작다는 뜻이다.
