> 작성 2026-11-06. 사전등록: spec `scenarios_m3.m3a`(연구자 승인 2026-11-06), 세부는 `m3_prereg_draft_KO.md`.
> **M3a에는 go/no-go 판정이 없다.** 아래는 사전등록한 보고 항목을 그대로 적은 것이고, 다음 단계는 연구자가 정한다.
> 숫자 출처: `results/system/m3a/summary_by_year.csv`, `summary.json`, `fig_d_by_year.png` (`python -m gbess.system.m3a summary`). 해마다의 판은 `results/system/m1/w{해}_x{배율}_{설계안}/`, 순차 재급전은 `results_sequential_w1n_increment_{해}.csv`. 단위 £m/년(2030, 2025년 £), TWh. status: derived (모형 출력).

## 1. 무엇을 돌렸나

- 2030년 3구역 모형(M1과 같은 코드·입력 규칙, 입력 수정 ② 포함)을 기상연도 2010~2024년 15개 해로 돌렸다. 2013·2020은 M1 결과를 그대로 썼다.
- 새 해 13개 × 6판 = 78개 작업: S0 한도 ×0.8·×1.0·×1.2, S1a·S1b ×1.0, 순차 재급전 ×1.0.
- 2026-11-06 13시 30분에 시작해 19시 15분쯤 끝났다(8개 동시, 약 5시간 45분). 78개 모두 정상 종료, 풀이 상태는 모두 "Optimal". 다시 돌린 판은 없다.
- 판에 적힌 코드 버전은 4547cc5·a45c5f3이다. 두 버전 사이에 모형 코드(`gbess/system`의 m3a.py 밖)는 바뀌지 않았다(`git diff d075bf1 HEAD -- gbess/system`).

## 2. 검산과 "비교 불가"

- ×1.0·×1.2: 15개 해 모두 검산 위반이 없다.
- ×0.8: 4개 해가 검산을 통과하지 못해 사전등록 규칙("검산이 깨진 판은 '비교 불가'로 따로 셈")에 따라 ×0.8 분포에서 뺐다.

| 해 | 깨진 항목 |
| --- | --- |
| 2016 | C(S0, iii 첫 풀이) ≤ C(S0, i)가 £59.8m 차이로 성립 안 함 |
| 2017 | D_lo ≤ D_hi가 £4.1m 차이로 성립 안 함 |
| 2021 | D_lo ≤ D_hi가 £90.8m 차이로 성립 안 함 |
| 2022 | D_lo ≤ D_hi가 £41.6m 차이로 성립 안 함 |

- 원인은 M1과 같다(`m1_results_KO.md` 5장 1번, 6.1). ×0.8에서는 **15개 해 모두** W1 북쪽을 1단계 계획에 묶으면 풀 수 없는 시간이 있어, `min_deviation`(이탈량을 먼저 줄이고 그다음 비용)으로 풀었다. 이탈량이 판마다 달라 비용 순서가 보장되지 않는다.
  - ×0.8 (iii) 이탈량: 첫 풀이 229~337 GWh, D_lo 60~181 GWh, D_hi 337~560 GWh.
  - ×1.0·×1.2의 (iii)은 15개 해 모두 이탈이 0이다. 주 결과(×1.0)는 이 문제가 없다.
- 남은 11개 해의 ×0.8도 이탈을 포함한 값이다. 검산이 "우연히" 맞았을 뿐이라는 M1의 한계가 그대로 남는다.
- 요약 코드 고침(결과를 본 뒤, 사전등록 규칙을 코드에 맞춘 것): 처음 요약 코드는 깨진 판도 분포에 넣고 있었다. 위반을 한도 배율별로 세어 그 배율에서만 빼도록 고치고, 손계산 시험을 늘렸다(`tests/test_system_m3a.py`). 지표·해·판은 바꾸지 않았다.

## 5. 설계안 순위 (2013년과 같은가)

순위는 낮을수록 좋음, 괄호는 (S0, S1a, S1b), £0.1m 미만 차이는 같은 순위(사전등록 세부).

**계통 총비용**: 2013 순위 (1, 0, 2) = S1a < S0 < S1b. **같은 해 5개 / 15개**(2013, 2016, 2021, 2022, 2024).
- 뒤집힌 10개 해 중 9개(2010, 2011, 2012, 2014, 2015, 2017, 2019, 2020, 2023)는 (0, 1, 2) = S0 < S1a < S1b. S0과 S1a 자리만 바뀌었다.
- 2018은 (2, 0, 1) = S1a < S1b < S0.
- **S1b가 가장 비싼 해는 14개**(2018만 예외).
- S0과 S1a의 차이는 2018(+107.0)·2024(+27.0)을 빼면 모두 ±10 안이다(−9.6 ~ +6.8).

**소비자 지급**: 2013 순위 (0, 1, 2) = S0 < S1a < S1b. **같은 해 11개 / 15개**.
- 뒤집힌 해: 2010·2018은 S1a와 S1b 자리가 바뀜(0, 2, 1). 2016·2021은 S1a가 가장 작음(1, 0, 2).
- S0의 소비자 지급이 가장 작은 해는 13개다.

## 7. 눈에 띄는 점 (보고만, 판정 아님)

1. **2018년과 정전 비용.** 2018 S0 (iii) D_lo 판에는 정전(공급 부족)이 6.62 GWh 있다. VoLL £17,000/MWh를 곱하면 £112.5m로, D_lo 143.9의 대부분이다. 같은 해 S1a·S1b D_lo 판에는 정전이 없다(S6 판은 정전량 열을 따로 남기지 않는다).
   - 정전이 있는 S0 ×1.0 D_lo 판은 4개 해다: 2011 1.83 GWh(£31.0m), 2013 1.06(£18.0m), 2018 6.62(£112.5m), 2024 1.65(£28.0m).
   - 이 네 해는 C(S0) − C(S1a)가 큰 해와 겹친다(2013 +6.8, 2018 +107.0, 2024 +27.0). S1a의 이점이 큰 해는 대부분 "W1 북쪽을 전국 가격 계획에 묶으면 남쪽에 공급 부족이 생기는 시간"이 있는 해라는 뜻이다. 예외는 2011로, 정전 비용 £31.0m가 있는데도 S1a가 S0보다 비싸다(S1a에도 정전 1.8 GWh가 있음).
   - 정전 비용을 빼고 본 값(D_lo − VoLL × 정전량)은 회계상 나눈 것일 뿐 반사실(정전이 없었다면) 값이 아니다. 참고로 2011 21.3, 2013 29.4, 2018 31.4, 2024 40.2이다.
   - 정전이 언제 일어났는지(시간대)는 판 결과에 시간별 값을 저장하지 않아 아직 보지 않았다.
2. **2011년 W1 북쪽 몫 19.2.** W1 북쪽을 포함한 D_seq(281.3)는 다른 해와 비슷하다. 그런데 W1 북쪽을 뺀 구역망의 D_seq가 262.2로, 다른 해(135~200)보다 훨씬 크다. 그래서 차이가 작게 나왔다. 왜 그런지는 보지 않았다(판단에 쓰지 않는 값).
3. **S1b는 거의 늘 S0보다 비싸다**(14개 해, £21~59m). M1(2013)의 결론이 기상연도를 바꿔도 유지된다.
4. **S1a와 S0은 거의 비긴다.** 중앙값 −1.0으로 S0이 아주 조금 싸고, 부호가 해마다 바뀐다. 그래서 계통 총비용 순위는 2013과 같은 해가 5개뿐이다. 순위 "뒤집힘"의 대부분은 £10m 안의 차이에서 생긴다.
5. **한도 ×1.2에서는 3M을 넘는 해가 없다**(최대 37.3). ×0.8은 해에 따라 21.7~331.5로 크게 흔들리고, 묶은 저장 이탈 때문에 4개 해는 비교 불가다.
