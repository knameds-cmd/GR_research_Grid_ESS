# 내려받을 영국 핵심 논문 목록

작성 2026-10-07. 이 환경에서는 ScienceDirect, RSC, IEEE, arXiv 접근이 막혀 있어 본문을 읽지 못했습니다. 아래 논문의 PDF를 학교 계정으로 받아 주시면 해당 아카이브 파일을 전문 기준으로 다시 정리하겠습니다. 파일명은 표의 `id`를 쓰면 됩니다(예: `gale2026_balancingbatteries.pdf`).

> **저작권 주의**: 이 저장소는 공개 저장소라서 출판사 PDF를 커밋하면 안 됩니다. `literature/pdf/`는 `.gitignore`에 넣어 두었습니다. PDF는 그 폴더에 두고 쓰시고, 제가 읽어야 할 때는 이 세션에 직접 업로드해 주세요. 오픈액세스(CC-BY, arXiv 등)는 링크만 적어 두면 됩니다.

**표기**
- 서지 상태: `확인` = 아카이브나 OpenAlex 조회로 확인됨, `검색` = 2026-10-07 검색 결과로만 확인됨, `기억` = 기억에 의존한 후보라 받을 때 제목·권호·DOI를 확인해야 함.
- 아카이브: `abstract` = 초록만 정리되어 있음, `없음` = 아직 파일이 없음, `full` = 이미 전문 기준으로 정리됨.
